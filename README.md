# Как это работает

Через консольное меню в main вы выбираете для какой из четырех функций
и каким методом программа вычислит первые два нетривиальных корня. В этот момент
j0, j1, y0, y1 инициализируются как объекты класса BesselFunction. 

Через этот класс для каждой функции бесселя можно вызвать рассчет
корней любым из трех предложенных в задании методом. Их механизм работы 
описан в модулях пакета methods.
